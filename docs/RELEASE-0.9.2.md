# 0.9.2: simpler Settings

Settings groups dictation, preferences and account actions into distinct sections. Action buttons share a neutral rounded style, keyboard focus indicators and matching line icons. Dictation key capture has an explicit prompt and cancel instructions. Language includes Translate to English.

Settings opens once on first launch; there is no Finish setup step. Test microphone optionally shows the live input level without starting a dictation. Closing Settings hides the test. Check for updates reports progress in Settings, and Quit closes the app. The pause, retry and discard buttons have been removed.

Existing sign-in, microphone, language, shortcut and startup preferences are preserved. This source update uses the existing Python 3.13 bundle and adds no dependencies.

Tommy approved the preview and authorized release. Native Windows UI tests and visual checks covered light/dark themes and 100%, 150% and 200% display scaling. Release build and installation checks are recorded with the publication evidence.
